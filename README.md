# СинемаБлокнот — лабораторная работа №8
## Требования
- Node.js LTS
- npm
- Для E2E-тестов — браузер Chromium от Playwright

В `src/api/moviesApi.test.ts` проверяются синхронные функции нормализации:
- преобразование возрастных ограничений;
- преобразование ответа API в модель фильма;
- запасные значения для пустых и некорректных данных;
- отсутствие повторяющихся тегов.

В `src/api/moviesApi.async.test.ts` проверяются асинхронные функции:
- успешная загрузка списка фильмов;
- обработка ошибки API;
- поиск по ключевому слову;
- отклонение ответа неправильного формата.

Ответ API подменяется Jest-моком `httpGet`. Проверяемые функции `getMovies` и `searchMovies` не подменяются.

## E2E-тесты Playwright

Playwright автоматически запускает Vite на `http://127.0.0.1:4173`. Внешний API не вызывается: сетевой ответ каталога подменяется через `page.route`. Проверяются пользовательские сценарии:
- добавление фильма в желаемое;
- поиск фильма;
- открытие карточки и просмотр описания.


## Структура тестов

- `src/api/moviesApi.test.ts` — синхронные unit-тесты Jest.
- `src/api/moviesApi.async.test.ts` — асинхронные тесты Jest с мокированием HTTP-ответа.
- `e2e/catalog.spec.ts` — сквозные пользовательские тесты Playwright.

Тесты независимы: каждый E2E-сценарий получает собственную страницу и собственный подменённый ответ API. Тестовые данные не требуют реального API-ключа.
