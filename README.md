# СинемаБлокнот — лабораторная работа №8

Проект лабораторной №7 на React + TypeScript дополнен автоматическими тестами Jest и Playwright. Само приложение не переписывалось.

## Требования

- Node.js LTS
- npm
- Для E2E-тестов — браузер Chromium от Playwright

## Установка и запуск приложения

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте `.env` на основе `.env.example` и добавьте ключ Kinopoisk Unofficial API:

   ```env
   VITE_KINOPOISK_API_KEY=ваш_ключ
   ```

3. Запустите приложение:

   ```bash
   npm run dev
   ```

Ключ API берётся из `.env`. Vite подставляет его при сборке; обращение к `process.env` в `http.ts` выбрано так, чтобы Jest не пытался разобрать `import.meta`, который несовместим с CommonJS-трансформацией тестов.

## Проверка TypeScript и сборки

```bash
npm run typecheck
npm run build
```

## Unit- и интеграционные тесты Jest

```bash
npm test
```

В `src/api/moviesApi.test.ts` проверяются синхронные функции нормализации:
- преобразование возрастных ограничений;
- преобразование ответа API в модель фильма;
- запасные значения для пустых и некорректных данных;
- отсутствие повторяющихся тегов.

В `src/api/moviesApi.async.test.ts` проверяются асинхронные функции:
- успешная загрузка списка фильмов;
- обработка ошибки API;
- поиск по ключевому слову;
- отклонение ответа неправильного формата.

Ответ API подменяется Jest-моком `httpGet`. Проверяемые функции `getMovies` и `searchMovies` не подменяются.

## E2E-тесты Playwright

Один раз установите браузер:

```bash
npx playwright install chromium
```

Запустите тесты:

```bash
npm run test:e2e
```

Playwright автоматически запускает Vite на `http://127.0.0.1:4173`. Внешний API не вызывается: сетевой ответ каталога подменяется через `page.route`. Проверяются пользовательские сценарии:
- добавление фильма в желаемое;
- поиск фильма;
- открытие карточки и просмотр описания.

## Все проверки одной командой

```bash
npm run test:all
```

## Структура тестов

- `src/api/moviesApi.test.ts` — синхронные unit-тесты Jest.
- `src/api/moviesApi.async.test.ts` — асинхронные тесты Jest с мокированием HTTP-ответа.
- `e2e/catalog.spec.ts` — сквозные пользовательские тесты Playwright.

Тесты независимы: каждый E2E-сценарий получает собственную страницу и собственный подменённый ответ API. Тестовые данные не требуют реального API-ключа.

## Что добавлено для лабораторной №8

- Jest и TypeScript-конфигурация для тестирования.
- Синхронные тесты обычных и граничных данных.
- Асинхронные тесты успешного ответа, ошибки и некорректного формата данных.
- Подмена HTTP-ответа без подмены тестируемой функции.
- Playwright-тесты действий пользователя в браузере.
- Команды `npm test`, `npm run test:e2e` и `npm run test:all`.

## Публикация

Загрузите проект в GitHub без папок `node_modules`, `dist` и файла `.env`. Не публикуйте настоящий API-ключ. Для сдачи отправьте ссылку на репозиторий и приложите вывод команд `npm test`, `npm run test:e2e` и `npm run build`.
